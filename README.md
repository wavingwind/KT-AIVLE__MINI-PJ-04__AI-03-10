| **BookEditPage** | `/books/:id/edit` | 기존 도서 정보 수정 페이지 (기존 데이터 로드 및 `PATCH /books/:id`) | 남건우 |

| **기능** | **Method** | **Endpoint** | **요청 데이터 (Body) / 비고** |
| --- | --- | --- | --- |
| **메인 페이지 (기존 도서 목록 조회)** | `GET` | `/books` | 전체 도서 배열 반환 (`db.json`) 후 프론트에서 `category`별 그룹핑 렌더링 |

| **AI 표지 이미지 생성** | `POST` | `/cover-gen` | `{ model: “gpt-image-…, prompt, … }` |
| **좋아요 상태 변경** | `PATCH` | `/books/{id}` | `{ isLiked: boolean }` |

# **5.** AIVLE 문고 **기본기능**

## **5-1. 도서 등록 페이지 (`BookCreatePage`)**

장르(SelectButton), 작가명, 제목, 내용(textarea)을 입력받아 신규 도서를 등록합니다.

AI로 도서표지 이미지를 생성할지 (표지 생성 안함 / 표지 생성)을 선택가능. 

표지 생성 선택 시에만 품질(low / medium / high)과 OpenAI API Key 입력칸이 활성화. 이미지 생성을 하지 않으면 기본 표지로 출력.

표지 생성 중에는 미리보기 영역에 로딩 스피너를 표시하고 모든 하단 버튼(취소, 저장 및 생성, 목록)을 비활성화(disabled)하여 중복 요청 방지.

## 5-2. 도서 정보 수정 페이지 **(`BookEditPage`)**

새로 값을 작성할 필요없이 기존에 작성했던 값을 불러온 후 이어서 수정할 수 있습니다.

URL 파라미터(id)로 기존 도서 데이터를 불러와 장르, 작가명, 제목, 내용, 기존 표지 이미지를 입력칸과 미리보기 박스에 자동으로 채움.

기본값은 표지 유지 상태로 기존 표지를 보존하며, 표지 재생성 선택 시에만 품질과 OpenAI API Key 입력칸이 활성화되어 새 표지로 교체 가능.

재생성 및 수정 클릭 시 수정된 도서 정보와 표지 URL을 PATCH 요청으로 반영하고, 재생성 완료 후 옵션과 API Key 입력 상태를 초기값(표지 유지)으로 복귀.

취소 버튼 클릭 시 변경 사항을 저장하지 않고 해당 도서의 상세 페이지(/books/:id)로 이동.

## 5-3. 도서 표지이미지 생성

`gpt-image-2` 모델을 호출하여 도서 표지이미지를 생성합니다.
`b64_json` 값으로 생성된 이미지를  `Data URL`로 변환하여 이미지를 출력합니다.

브라우저에서 json 서버로 데이터 보내면 json 서버가 db에 저장.
AI(이미지모델)에게 POST 요청을 보냄. AI가 그에맞는 이미지를 생성해서 b64_json 형식으로 React에게 응답.
React는 Data URL로 바꾸고 json서버한테 수정해달라고 Patch.
AI와 json server는 직접 소통하지 않음.

## 5-4. 도서 목록 페이지

도서를 장르별로 묶어서 보여줌.
한 줄마다 해당 장르 도서들의 표지 이미지들을 가로방향으로 보여줌.

가로 스크롤 가능. 넘김버튼 추가.

약간의 공백을 두고 그 아랫 줄에는 같은 방식으로 다른 장르의 책들 표지를 띄움.

## **5-5. 도서 상세 페이지** **(`BookDetailPage`)**

도서 표지를 클릭하면 제목, 저자, 출판사, 줄거리 내용 등을 확인할 수 있는 상세페이지로 이동

## 5-7. 도서 검색 기능

수정이나 삭제할 타겟도서를 찾기 위한 검색기능

## **5-7. 상단 고정 글로벌 내비게이션 헤더**

헤더에 홈버튼. 스크롤 내려도 페이지에서 안사라지고 윗부분에 고정되게. (Fixed)

# 6. AIVLE 문고 부가기능

## **6-1. 선호작 기능**

마음에 드는 도서에 버튼을 눌러 선호작 표시 하면 DB에 저장. 
선호작으로 저장된 작품들을 모아볼 수 있는 페이지 추가.

## 6-2. **유효성 검사.**

도서 정보 추가 및 수정할 때 입력 형식 맞는지 검사.

저장 시 유효성 검사(장르 선택 여부, 필수 텍스트 입력, API Key 및 품질 선택 여부)를 통과하면 수정 페이지(/books/:id/update)로 이동.

특수문자 아예 타이핑이 안되게.
만약 입력 칸에 특수문자 있을때 에러메시지 출력.

# 7. 나중에 추가할 기능

## **7-1. 도서 표지에 호버기능으로 상세 정보 오버레이**

마우스를 올리기 전에는 표지랑 제목만 보이게.

마우스 올리면 표지 이미지 위로 도서의 세부 내용(저자, 출판사, 줄거리 요약 등)도 작은 글씨로 보이게.

## **7-2. 메인화면에 베스트셀러 띄우기**

메인페이지에서 베스트셀러를 장르처럼 넣어서 젤 위에 노출되게.

지금은 사용자가 한명이지만, 사용자 여러명이 수정 가능한 상태가 될 때 대비해서 내가 올린 도서 목록 볼 수 있게.
다른 사용자들 데이터랑 병합하여 집계할 수 있도록 확장대비.

## 7-3. 표지이미지 후보를 여러개 생성

ai표지 생성할때, 여러 개 중에서 고를 수 있는 기능.

표지 세개를 보여줘야 되니까 한다면 정렬 같은 것도 바꿔야 함.

## 7-4. 북카드 호버 기능

북카드의 표지이미지에 마우스를 올리면 저자, 출판사, 줄거리 요약 등을 오버레이로 표시

## 7-5. 표지이미지 수동 추가 기능

표지이미지를 AI로 생성하지 않을 시에, 사용자가 가지고 있는 이미지 파일을 업로드 할 수 있게.
